# RepoGuard v0.6: Safe Benchmark Pack and Automatic Comparison

## What v0.6 adds

### 1. Repository isolation

Benchmark tasks run against a temporary copy of each source repository by default.

This protects the original benchmark fixture from accidental mutation and makes repeated runs reproducible.

### 2. Expanded benchmark pack

The v0.6 suite contains four controlled Python tasks:

- arithmetic logic bug
- string normalization bug
- boundary-condition bug
- boolean access-logic bug

Task file:

```text
benchmarks/v0.6_tasks.json
```

### 3. Automatic comparison reports

RepoGuard can combine one or more JSONL experiment logs and generate:

- CSV comparison output
- Markdown comparison table

Example:

```bash
repoguard-compare \
  artifacts/baseline.jsonl \
  artifacts/tools.jsonl \
  artifacts/full-repoguard.jsonl \
  --csv-out artifacts/comparison.csv \
  --markdown-out artifacts/comparison.md
```

### 4. Safe benchmark command

```bash
repoguard-benchmark benchmarks/v0.6_tasks.json \
  --backend gemma \
  --model-id google/gemma-4-12B-it \
  --experiment-id baseline-v001
```

Each task runs in its own temporary working copy. The source fixtures remain unchanged.

## Metrics used in comparison

- task count
- fixed count
- fix rate
- test-pass rate
- average steps
- average latency
- human-intervention rate
- proposal counts
- approval / rejection counts

## Recommended experiment sequence

Run the same task pack with:

1. baseline-v001
2. tools-v001
3. planning-v001
4. verification-v001
5. governance-v001
6. full-repoguard-v001

Then combine the JSONL logs with `repoguard-compare`.
