# RepoGuard v0.3: Autonomous Repair Loop

RepoGuard now has a bounded model/tool loop for software repair.

## Supported actions

The model can request one action at a time:

- list repository files
- read a file
- search repository text
- run tests
- write a low-risk file
- finish with an evidence-based status

## Governance

RepoGuard checks each requested write before applying it. Sensitive changes are not applied automatically and are escalated for human approval.

## Repair policy

1. Inspect relevant code before editing.
2. Prefer the smallest change that addresses the issue.
3. Use test feedback before declaring success.
4. Stop after a bounded number of steps.
5. Preserve the action and observation trail in the audit ledger.
